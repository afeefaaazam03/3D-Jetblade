# BladeDelta demo

Five sealed-test cases with the frozen model's real outputs (v1 and v1.1). This Space has no GPU, so results are
precomputed; run `demo/app.py` from the code repository on a GPU machine to re-run the method live or on your own data.

Code and paper: https://github.com/afeefaaazam03/3D-Jetblade/tree/main/code
