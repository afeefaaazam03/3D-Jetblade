Does the photograph support a dent?

Pick a blade. The method compares two photographs with the healthy CAD model and reports a dent, with its depth, only when the images support it better than camera error, lighting or a stain. Otherwise it says not supported. These are the frozen model's real outputs on sealed-test blades it never saw during development.

Run it yourself

The full interactive app (Gradio) runs the method live on a GPU, including on your own photographs and CAD mesh:

git clone https://github.com/afeefaaazam03/3D-Jetblade && cd 3D-Jetblade/code
pip install -r requirements.txt gradio && pip install git+https://github.com/NVlabs/nvdiffrast.git --no-build-isolation
python demo/app.py

Or open the Colab notebook in code/notebooks/. Inputs must come from the BladeDelta camera rig; real photographs are pending physical validation.
